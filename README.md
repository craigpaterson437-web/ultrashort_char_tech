This repository contains code created during my masters project (under the suprvision of Dr Steven Magennis and Ms Abigial Thom), working on single molecule fluorescene techniques using ultrafast lasers. The files are, in the main, working tools that I created to simulate experimental ideals or handle generated data. As such the code is quite rough and ready and potentially un-functional in some aspects. It is also quite sparsely commented at the time of first publication but I aim to improve this over time. 
gaussian_simulated_dispersion.py is the most useful to a wider audience as it models optical pulse dispersion under the effects of Group Delay Dispersion (GDD). It aligns closely with mathematical predictions and is wrapped up into a neat tool. This could easily be mirrored for other functional descriptions of Ti:Sapphire laser pulses including sech^2.

Some code is in .ipynb notebooks as for me this is easier to work with. Furthermore most graphs have saving functionality to integrate with my workflow. However the more functional tools are in .py form as I have bundled these into apps for future group use. 

For the analysis of IAC graphs generated by MIIPS ver. 2.0 software, SHG_IAC_RUN_2.py is required along with its associated functions file, SHG_IAC_function.py. 

For the creation of phase and gaussian shaped amplitude masks (functionality for binary masks coming soon) then mask_maker_run.py is required along with mask_maker_functions.py.
